# Kunipy

Kunipy 是一个基于 Python 的 AI 角色平台，重点支持持久记忆、角色人格、多模态交互、工具、集成以及可扩展架构。

项目最初受到 [Kuni](https://github.com/Alex2772/kuni) 的启发，并曾以 Python 实现相关思路。此后项目经过大幅重构和扩展，目前已经成为独立的 Python 代码库。

## 主要功能

- AI 角色与人格层
- 持久记忆和语义检索
- 日记与长期上下文
- Telegram 集成
- Web/代理集成
- 多模态能力
- 语音和语音合成组件
- 图像生成支持
- 指标与监控
- 可扩展的应用架构

详细内容请参阅[文档](docs/README.md)。
