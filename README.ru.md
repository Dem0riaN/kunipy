# Kunipy

**Kunipy** — Python-платформа для ИИ-персонажа с долговременной памятью, характером, Telegram-взаимодействием, инструментами, мультимодальными возможностями и расширяемой архитектурой.

Проект изначально создавался как Python-реализация, вдохновлённая [Kuni](https://github.com/Alex2772/kuni). В дальнейшем код и архитектура были существенно переработаны и расширены. Текущий Kunipy — самостоятельная Python-кодовая база; исходный C++-код Kuni в неё не входит.

## Возможности

- редактируемые prompt-файлы характера и внешности;
- Telegram userbot через TDLib;
- постоянный дневник с embeddings и семантическим поиском;
- гибридная память ChromaDB + SQLite;
- автоматическое извлечение долговременных воспоминаний из диалогов;
- working memory для обещаний, планов и незавершённого контекста;
- sleep/consolidation;
- мультимодальная обработка сообщений;
- генерация изображений через совместимый со Stable Diffusion API backend;
- TTS и отправка голосовых сообщений;
- web search;
- OpenAI-compatible proxy;
- Prometheus metrics;
- dependency injection и слоистая архитектура.

## Быстрый старт

### Требования

- Python 3.11+
- OpenAI-compatible LLM endpoint
- Telegram API ID/hash, если включён Telegram
- дополнительные backend'ы для необязательных возможностей

### Установка

```bash
git clone https://github.com/Dem0riaN/kunipy.git
cd kunipy

python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e .
```

### Настройка

```bash
python run.py
```

Используй `config.example.toml` как полный справочник параметров.

Не добавляй реальные ключи и пароли в Git.

### Запуск

```bash
python run.py
```
