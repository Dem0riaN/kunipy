# Kunipy

Kunipy — Python-платформа для ИИ-персонажа с долговременной памятью, характером, мультимодальным взаимодействием, инструментами и расширяемой архитектурой.

Проект изначально создавался как Python-реализация, вдохновлённая проектом [Kuni](https://github.com/Alex2772/kuni). В дальнейшем код и архитектура были существенно переработаны и расширены, поэтому текущий Kunipy является самостоятельным Python-проектом.

## Основные возможности

- слой характера и личности ИИ-персонажа;
- долговременная память и семантический поиск;
- дневник и долгосрочный контекст;
- интеграция с Telegram;
- web/proxy-интеграции;
- мультимодальные возможности;
- компоненты речи и синтеза;
- генерация изображений;
- метрики и мониторинг;
- расширяемая архитектура приложения.

Подробности находятся в [документации](docs/README.md).
