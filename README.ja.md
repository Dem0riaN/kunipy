# Kunipy

Kunipy は、永続メモリ、人格、多モーダル対話、ツール、各種インテグレーション、拡張可能なアーキテクチャを備えた Python ベースの AI キャラクタープラットフォームです。

このプロジェクトは当初、[Kuni](https://github.com/Alex2772/kuni) に着想を得て Python で関連する機能を実装するところから始まりました。その後、コードとアーキテクチャは大幅に再設計・拡張され、現在は独立した Python コードベースとなっています。

## 主な機能

- AI キャラクターと人格レイヤー
- 永続メモリとセマンティック検索
- 日記と長期コンテキスト
- Telegram 連携
- Web / proxy 連携
- マルチモーダル機能
- 音声・音声合成コンポーネント
- 画像生成
- メトリクスと監視
- 拡張可能なアプリケーションアーキテクチャ

詳しくは[ドキュメント](docs/README.md)を参照してください。
