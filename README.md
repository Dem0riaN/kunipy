# Kunipy

Kunipy is a Python-based AI character platform focused on persistent memory, personality, multimodal interaction, tools, integrations, and extensibility.

The project originally started as a Python reimplementation inspired by [Kuni](https://github.com/Alex2772/kuni). It has since been substantially redesigned and expanded into an independent Python codebase.

## Highlights

- AI character/personality layer
- Persistent memory and semantic retrieval
- Diary and long-term context
- Telegram integration
- Web/proxy integrations
- Multimodal capabilities
- Text-to-speech and speech-related components
- Image generation support
- Metrics and monitoring
- Extensible application architecture

See the [documentation](docs/README.md) for details.
